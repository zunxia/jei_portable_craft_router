# 1.3.2 发布说明

## 修复内容

- 修复 ATM10 8.2 启动阶段因 NeoForge 配置尚未加载而崩溃的问题。
- 支持 ATM10 8.1 的 JEI `19.50.0.414` 和 ATM10 8.2 的 JEI `19.57.0.446`。
- 兼容 NeoForge `21.1.249`。
- 在 AE2 样板编码界面保留 AE2 原生的“编写样板”按钮，隐藏重复的附加按钮。
- 保留 AE2 可合成材料的蓝色提示和 Ctrl 点击自动合成缺失材料功能。

## 验证

- 8.2 场景 42–52：通过，记录见 `docs/validation`（本目录不随源码提交）。
- 配置早期读取回归：通过。
- 构建：43 个 Java 文件，零错误；仅有 4 条原有弃用警告。
- NeoForge：`21.1.249`。

## 安装

将 JAR 放入客户端和专用服务端的 `mods` 目录，确保两端版本一致，然后重启游戏或服务端。详细使用说明见根目录 `README.md`。
