# 1.3.4 发布说明

修复 ATM10 7.3 的 JEI `19.43.0.392` 被版本白名单禁用的问题，取消所有按 JEI 版本号判断是否启用和选择适配器的逻辑。

## 功能与兼容

- 核对 248 个 Minecraft 1.21.1 NeoForge JEI 构件，对 **19.27.0.335–19.57.0.451 的全部 83 个已发布版本**完成接口适配。
- 控制器和布局按实际接口分别匹配，兼容 `.421/.422` 的混合结构。
- 处理较早版本缺少 `getOptionalJeiRuntime` 和 `canSendPacket` 的差异。
- 保留自动合成蓝色提示、Ctrl 合成确认、样板按钮去重、材料预检、服务端握手和物品校验。

## 验证

全部 83 个构件接口审计通过，具体游戏回归结果见 [VALIDATION-P8.md](VALIDATION-P8.md)。修改隔离 JEI 的版本元数据为 `19.58.0.0` 后仍能完成真实配方跳转，确认取消了版本号限制。

`.335`、`.389`、ATM10 7.3 原版 `.392`、`.451` 各通过完整 53 个隔离游戏场景；`.421` 的自动合成与样板场景 42–52 通过。完整整合包冲突和本轮专用服务端双客户端矩阵未重新验证。

## 安装

成品 `jei_portable_craft_router-1.3.4.jar`，85227 字节。SHA-256：`9057B32CE4334F633C1E66BF40C1C524C5E4D2ECFDAFE75BCBA92129B6061F54`。替换客户端和专用服务端的旧路由模组后重启，单人只需更新客户端。无需更换 ATM10 7.3 的原 JEI。不要安装测试探针 `router_probe.jar`。

更早的 `19.25.1.334` 及以下使用另一套按钮架构，当前未实现其界面。其他 Minecraft 版本、Forge/Fabric 不在此次范围。没有版本白名单不代表未来接口变化自动兼容。
