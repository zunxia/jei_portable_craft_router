# 1.3.3 发布说明

Minecraft 1.21.1 NeoForge 的 JEI 兼容范围扩展为 **19.50.0.414–19.57.0.451 内全部 30 个已发布版本**，包含 Beebeeblock - The Skyhive 使用的 **19.57.0.449**。

## 改动

- 修复 1.3.2 因仅接受 `.414`、`.446` 而在其他 JEI 版本禁用功能的问题。
- 分别选择配方按钮控制器和布局适配器，兼容 `.421/.422` 的过渡 API 结构。
- 继续调用各 JEI 版本的原生转移实现；保留 AE2 蓝色自动合成提示、Ctrl 合成确认、样板编码和原生按钮去重。
- 保留未验证版本和签名不匹配时的安全禁用。
- 增加真实 JEI 构件矩阵检查脚本，以及隔离客户端的 `-JeiJar` 参数。

## 验证

全部 30 个真实 JEI 构件的类型、成员、注入签名、反射入口及转移包检查通过。运行回归版本、环境和原始日志位置见 [VALIDATION-P7.md](VALIDATION-P7.md)。NeoForge 21.1.249 构建通过，保留 4 条原有弃用警告。

`.414`、`.421`、`.422`、`.423`、`.449`、`.451` 各完成 53 个隔离游戏场景，每组 376 条通过记录。未知版本启动保护检查通过。未进行完整整合包和本轮专用服务端双客户端复测。

## 安装包

- 文件：`jei_portable_craft_router-1.3.3.jar`
- 大小：87,078 字节
- SHA-256：`CD93F916AE86B2A72563CBF7157BF57455999C3FCD2F57BC31313057C7710569`

替换客户端和专用服务端 `mods` 中的旧版路由模组，确保两端一致，然后重启。单人只需更新客户端。测试探针 `router_probe.jar` 不用于正式游戏。JEI 及其他依赖仍需自行满足相互版本要求。

Skyhive 的 AE2 Lightning 2.1.1、Polymorph 1.1.0 存在独立的旧 JEI mixin 冲突，本次更新不修复这两个模组；核心依赖测试通过不代表完整整合包所有冲突已消除。
